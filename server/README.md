# Сервер панели розыгрышей

Бэкенд для `panel.html`. Один Node.js-процесс:

- отдаёт саму панель и её файлы (`panel.html`, `app.js`, стили, картинки);
- держит WebSocket с панелью и отправляет ей состояние и события рулетки;
- читает чат Twitch и добавляет в розыгрыш тех, кто написал кодовое слово (по умолчанию `+`);
- считает сообщения и время в чате, хранит победителей, чёрный список и историю игроков;
- отвечает на все запросы `/api/...`, которые делает панель.

> **Важно.** GitHub Pages (`*.github.io`) умеет только отдавать файлы, WebSocket он не принимает.
> Панель нужно открывать с адреса этого сервера, а не с GitHub Pages. Именно из-за этого на
> `github.io` панель вечно показывает «Подключение...».

## Быстрый старт

```bash
cd server
npm install
ADMIN_KEY=придумай-длинный-ключ TWITCH_CHANNEL=wokomilka npm start
```

Открой один раз `http://localhost:3000/panel.html?key=придумай-длинный-ключ`.
Сервер запомнит вход в браузере (cookie), дальше ссылку можно открывать без ключа.
Если вход потерян, панель покажет окно ввода ключа.

Нужен Node.js 18 или новее. Если `ADMIN_KEY` не задан, ключ создаётся сам, сохраняется в файле
данных и печатается в консоли при первом запуске. Не используй `12345`: это значение
лежит в публичном репозитории.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ADMIN_KEY` | создаётся сам | Ключ входа в панель |
| `TWITCH_CHANNEL` | `wokomilka` | Канал, чат которого читаем |
| `PORT` | `3000` | Порт сервера |
| `DATA_FILE` | `server/data/data.json` | Где хранятся данные. На хостинге укажи путь на постоянном диске |
| `TWITCH_BOT_NICK`, `TWITCH_BOT_OAUTH` | пусто | Аккаунт бота и его токен (`oauth:...`). Нужны только чтобы писать в чат кнопкой «SEND». Без них чат читается анонимно |
| `IGNORED_USERS` | nightbot, streamelements, moobot, streamlabs, wizebot, fossabot | Боты, которых не считаем участниками и в статистике (через запятую) |
| `TRUST_PROXY` | выкл | Поставь `1`, если сервер стоит за прокси (Render, Railway, nginx): тогда IP берётся из `X-Forwarded-For` |
| `STATIC_DIR` | корень репозитория | Откуда отдавать панель |
| `TZ_NAME` | `Europe/Moscow` | Часовой пояс для времени в чате и истории |

## Как это работает

- **Участники.** Любое сообщение чата, равное кодовому слову (без учёта регистра), добавляет
  автора в список один раз. Победители, игроки из чёрного списка и боты не добавляются.
  Кодовое слово меняется кнопкой «КОД» в панели.
- **Рулетка.** Режимы «обычная» и «на выбывание», «быстрый ролл» и реролл с причиной.
  Победитель убирается из участников и остаётся «выпавшим», пока его не сохранят (с суммой вывода)
  или не закроют. Переключатель «только не выигрывавшие» учитывается.
- **Watchtime** считается по чату: каждые 30 секунд начисляется тем, кто писал за последние 15 минут.
- **Данные** сохраняются в `DATA_FILE` и переживают перезапуск.

## Деплой

Подойдёт любой хостинг, где можно держать запущенный Node.js-процесс с WebSocket
(VPS, Render, Railway, Fly.io и т. п.):

1. Команда запуска: `cd server && npm install && npm start`.
2. Задай `ADMIN_KEY`, `TWITCH_CHANNEL`, `TRUST_PROXY=1`.
3. Подключи постоянный диск и укажи `DATA_FILE` на него, иначе данные пропадут при пересборке.
4. Открой выданный хостингом адрес: `https://твой-адрес/panel.html?key=...`.

Для OBS добавь ту же ссылку в браузерный источник.

## Что пока не сделано

- **«Как давно подписан»** (`/api/followage`) отвечает «нет данных». Для этого нужен токен Twitch API
  со scope `moderator:read:followers`.
- Список зрителей в чате для watchtime берётся по активности в чате, а не из Twitch API.

## Безопасность

- Без ключа API возвращает 401, а WebSocket не отдаёт состояние и не принимает команды.
- Ключ подставляется в `panel.html` только после входа; неавторизованным отдаётся пустое значение.
- Много неверных попыток подряд с одного IP блокируются на 10 минут.
- Папка `server/`, `.git` и файл данных по HTTP недоступны.
